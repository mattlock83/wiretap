# Security reporting

The security contact is the repository maintainer,
[@mattlock83](https://github.com/mattlock83).

Use GitHub's
[private vulnerability reporting](https://github.com/mattlock83/wiretap/security/advisories/new)
to contact the maintainer. Private reporting is enabled for this repository.
Keep vulnerability details, exploit steps, credentials and capture archives out
of public issues and discussions.

In the private report, include the Wiretap version and commit, affected command or
SDK integration, expected and observed behavior, and a minimal reproduction using
synthetic data. Describe the impact and any workaround you have found.

During prerelease development, fixes target the current `main` branch. Wiretap is
intended for isolated test environments with synthetic data and dummy secrets;
capture archives retain traffic unchanged. Report unexpected access, archive
corruption or unsafe filesystem behavior through the contact route above.
